## 🙋‍♂️ 소개 (About Me)

> **"단순히 돌아가는 코드가 아니라, '왜 이렇게 동작하는가'를 고민합니다."**

* 🎓 **전공**: 컴퓨터공학과 재학 중
* 💻 **주요 관심사**: 자료구조 및 알고리즘, 시스템 프로그래밍, 백엔드 아키텍처
* 🔍 **학습 태도**: 동작 원리를 깊이 파고들고, 새롭게 배운 지식을 기록으로 남기는 것을 좋아합니다.
* 🚀 **지향점**: 일상의 번거로운 문제를 소프트웨어와 자동화로 해결하는 개발자를 꿈꿉니다.
